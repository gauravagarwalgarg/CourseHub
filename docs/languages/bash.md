# 🐚 Bash / Shell Scripting

> Automate everything. The glue that holds Unix systems together.

## Learning Path

| Stage | Resource | Link |
|-------|----------|------|
| Beginner | The Missing Semester (MIT) | [missing.csail.mit.edu](https://missing.csail.mit.edu/) |
| Beginner | Bash Guide (Greg's Wiki) | [mywiki.wooledge.org/BashGuide](https://mywiki.wooledge.org/BashGuide) |
| Intermediate | Advanced Bash-Scripting Guide | [tldp.org/LDP/abs](https://tldp.org/LDP/abs/html/) |
| Advanced | ShellCheck (learn by linting) | [shellcheck.net](https://www.shellcheck.net/) |

| Tool | Use | Link |
|------|-----|------|
| awk | Text processing | [grymoire.com/Unix/Awk](https://www.grymoire.com/Unix/Awk.html) |
| sed | Stream editing | [grymoire.com/Unix/Sed](https://www.grymoire.com/Unix/Sed.html) |
| jq | JSON processing | [stedolan.github.io/jq](https://stedolan.github.io/jq/tutorial/) |
| xargs | Parallel execution | [man7.org/linux/man-pages](https://man7.org/linux/man-pages/man1/xargs.1.html) |
| tmux | Terminal multiplexer | [github.com/tmux/tmux/wiki](https://github.com/tmux/tmux/wiki) |
