## Understanding Licenses

| License | Type | Key Rule | Link |
|---------|------|----------|------|
| MIT | Permissive | Do anything, keep copyright notice | [opensource.org/licenses/MIT](https://opensource.org/licenses/MIT) |
| Apache 2.0 | Permissive | Patent grant included | [apache.org/licenses/LICENSE-2.0](https://www.apache.org/licenses/LICENSE-2.0) |
| GPL v3 | Copyleft | Derivatives must also be GPL | [gnu.org/licenses/gpl-3.0](https://www.gnu.org/licenses/gpl-3.0.en.html) |
| LGPL | Weak copyleft | Can link without GPL-ing your code | [gnu.org/licenses/lgpl-3.0](https://www.gnu.org/licenses/lgpl-3.0.en.html) |
| BSD 2/3-Clause | Permissive | Minimal restrictions | [opensource.org/licenses/BSD-2-Clause](https://opensource.org/licenses/BSD-2-Clause) |
| MPL 2.0 | File-level copyleft | Modified files must stay MPL | [mozilla.org/en-US/MPL/2.0](https://www.mozilla.org/en-US/MPL/2.0/) |
| Unlicense | Public domain | No restrictions at all | [unlicense.org](https://unlicense.org/) |

**Choose a license**: [choosealicense.com](https://choosealicense.com/)
